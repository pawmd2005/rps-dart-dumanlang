## Description
This is a game of Two-Player Rock, Paper, Scissors game created using Dart.

The game allows two players to:
- Enter their names
- Choose rock, paper, or scissors
- See the result of each round
- Keep track of their scores
- Play multiple rounds
- See the final score and overall winner

## Requirements
- Dart SDK
- Visual Studio Code
- Terminal

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

```bash
dart rock_paper_scissors.dart
